# 鹈鹕骑车酷跑

这是 [Licoy/tihuqiche](https://github.com/Licoy/tihuqiche) 项目的单文件离线 HTML 版本，用于通过 GitHub Pages 在线游玩。

游戏版权归原作者所有，原项目采用 MIT License；许可证见 [LICENSE](LICENSE)。

## 本地打开

直接用支持 WebGL 的浏览器打开 `index.html`。

## GitHub Pages

将本仓库 `main` 分支的根目录设为 Pages 发布源后，可通过 `https://maomao-1937.github.io/pelican-pedal-run/` 访问。
